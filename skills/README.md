# Skills Reutilizáveis

Este diretório não é mais parte de uma CLI.

Ele é um catálogo de processos que podem virar skills quando forem realmente
repetíveis.

## Critério Para Virar Skill

Um processo só deve virar skill quando tiver:

- gatilho claro;
- entradas esperadas;
- passos reproduzíveis;
- arquivos ou ferramentas envolvidos;
- critério de verificação;
- risco conhecido.

## Candidatos

- Registrar novo projeto no Codex Brain.
- Criar card de projeto.
- Atualizar grafo de relações.
- Criar brief para agente antes de trabalhar em um projeto.
- Revisar se um documento pode ser publicado sem vazar contexto privado.

## Não Criar Skill Para

- Simular cargo.
- Simular personalidade.
- Trocar estilo de fala sem processo.
- Guardar opinião solta.
