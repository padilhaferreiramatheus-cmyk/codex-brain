# Modelo De Privacidade

## Princípio

O cérebro global deve guardar o mínimo contexto útil.

## Níveis

### Público

Pode ser publicado sem dano esperado.

Exemplos:

- descrição geral de um projeto público;
- links públicos;
- roadmap sem informação sensível.

### Privado

Pode ajudar agentes, mas não deve ser publicado sem revisão.

Exemplos:

- caminhos locais;
- relações estratégicas;
- planos de produto;
- nomes internos.

### Sensível

Não deve ser versionado neste repositório.

Exemplos:

- senhas;
- tokens;
- arquivos `.env`;
- documentos pessoais;
- dados de clientes;
- contratos privados;
- conteúdo bruto de operações internas.

## Regra Para Agentes

Quando estiver em dúvida, trate como privado ou sensível e pergunte antes de
registrar.
