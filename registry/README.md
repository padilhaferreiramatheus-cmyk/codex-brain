# Registry

O registry é o índice dos projetos.

Ele responde:

- qual projeto existe;
- onde ele fica no disco;
- qual é o papel dele;
- qual é o nível de privacidade;
- quais outros projetos se relacionam com ele;
- qual arquivo local resume o projeto dentro deste cérebro global.

Fonte principal: `projects.yml`.

Cards humanos: `projects/`.
