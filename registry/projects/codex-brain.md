# Codex Brain

## Papel

Cérebro global de Matheus.

## Caminho

`C:\Projetos\CODEX BRAIN`

## O Que Guarda

- Registro dos projetos.
- Relações entre projetos.
- Regras globais de trabalho com agentes.
- Padrões de documentação.
- Glossário compartilhado.
- Decisões que afetam mais de um projeto.
- Resumos controlados, sem copiar projetos inteiros.

## O Que Não Guarda

- Código completo de outros projetos.
- Dados sensíveis.
- Arquivos `.env`.
- Bases internas completas.
- Conteúdo bruto de clientes.

## Relações

- Aponta para todos os projetos registrados.
- Ajuda agentes a escolherem quais contextos ler antes de trabalhar.
