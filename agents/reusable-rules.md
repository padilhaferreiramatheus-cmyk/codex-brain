# Regras Reutilizáveis Para Agentes

## Contexto Primeiro

Antes de trabalhar em um projeto registrado, leia:

1. o `AGENTS.md` local do projeto;
2. o card do projeto em `registry/projects/`;
3. relações relevantes em `graph/relations.yml`;
4. decisões globais em `docs/decisions.md`.

## Ponteiros, Não Cópias

Quando um projeto tiver documentação própria, aponte para ela. Não copie tudo
para o Codex Brain.

## Resumos Curtos

Todo resumo global deve responder:

- o que é;
- onde está;
- para que serve;
- com quais projetos se relaciona;
- que cuidados de privacidade existem.

## Privacidade Por Padrão

Quando o nível de privacidade não estiver claro, trate como privado.
