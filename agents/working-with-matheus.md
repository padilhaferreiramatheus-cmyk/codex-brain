# Como Trabalhar Com Matheus

Este arquivo guarda preferências globais de trabalho.

## Comunicação

- Responder em português do Brasil, salvo pedido contrário.
- Começar pelo resultado, impacto ou decisão.
- Explicar termos técnicos importantes na primeira vez em que aparecerem.
- Separar fatos encontrados, inferências, hipóteses e recomendações.
- Não inventar testes, dados, métricas, consenso, APIs ou decisões.

## Aprendizado

Matheus está aprendendo programação, mas consegue acompanhar detalhes técnicos
quando eles são explicados com clareza.

Ao mexer em código ou documentação:

- explicar primeiro o problema;
- depois explicar o comportamento esperado;
- então mostrar onde a solução se encaixa;
- indicar riscos e alternativas quando elas mudam o resultado.

## Git E Publicação

- Verificar o estado do repositório antes de mudanças relevantes.
- Preservar alterações preexistentes.
- Não descartar mudanças do usuário.
- Não fazer commit, push, PR, merge, deploy ou publicação sem autorização
  explícita.
- Ao mostrar comandos, dizer o que fazem e quais efeitos persistentes têm.

## Trabalho Com Agentes

- Usar o menor conjunto de skills necessário.
- Criar skill somente para processo repetido, com etapas e critério de
  verificação.
- Não criar skills para simular cargos, personalidades ou teatro operacional.
- Subagentes só devem ser usados quando trouxerem ganho real de análise
  independente.

## Definição De Concluído

Uma tarefa está concluída quando:

- o pedido foi atendido;
- a verificação proporcional ao risco foi feita;
- o diff foi revisado;
- documentação afetada foi considerada;
- não resta uma ação segura e necessária dentro do escopo autorizado.
