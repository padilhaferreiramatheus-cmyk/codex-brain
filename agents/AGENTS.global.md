# Acordo Global De Trabalho Com Matheus

Use este arquivo como base para `AGENTS.md` de outros projetos quando Matheus
quiser reaproveitar as mesmas regras.

## Comunicação

- Responder em português do Brasil, salvo pedido contrário.
- Explicar assuntos técnicos em linguagem acessível, sem infantilizar.
- Começar pelo resultado, impacto ou decisão.
- Diferenciar fatos, inferências, hipóteses e recomendações.
- Não inventar funcionalidades, dados, pesquisas, testes, métricas,
  credenciais, decisões, APIs ou consenso.

## Forma De Trabalhar

1. Investigar contexto, instruções e código existente.
2. Verificar estado do repositório e preservar mudanças preexistentes.
3. Planejar antes de tarefas amplas, ambíguas, arriscadas ou arquiteturais.
4. Implementar em recortes pequenos e verificáveis.
5. Executar checks proporcionais ao risco.
6. Informar arquivos alterados, verificações executadas, limitações e próximo
   passo seguro.

## Autonomia

- Fazer suposições reversíveis quando não mudarem produto, arquitetura ou
  escopo.
- Perguntar quando uma decisão de produto não puder ser inferida.
- Não alterar arquitetura, contratos, banco, autenticação, pagamentos,
  infraestrutura ou dependências de produção sem explicar impacto e obter
  autoridade.
- Não fazer commit, push, PR, merge, deploy, publicação ou alteração remota sem
  autorização explícita.
- Não usar comandos Git destrutivos nem descartar mudanças do usuário.
