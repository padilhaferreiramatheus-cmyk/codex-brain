# Contribuindo

Codex Brain agora é um cérebro global em arquivos.

Contribuições devem melhorar organização, clareza, privacidade e utilidade para
agentes.

## Antes De Alterar

Leia:

- `AGENTS.md`
- `registry/projects.yml`
- `graph/relations.yml`
- `docs/decisions.md`

## O Que É Bem-Vindo

- Cards de projeto mais claros.
- Relações melhores no grafo.
- Padrões de documentação reutilizáveis.
- Templates simples.
- Regras de agente mais úteis.

## O Que Evitar

- Copiar projetos inteiros para este repositório.
- Versionar dados sensíveis.
- Transformar o cérebro global em dashboard, banco ou CLI antes de necessidade
  real.
- Duplicar documentação que já vive no projeto de origem.
